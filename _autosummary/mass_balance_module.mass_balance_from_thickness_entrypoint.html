mass_balance_module.mass_balance_from_thickness_entrypoint

Command line entry point for converting ice thickness to mass balance.

Implemented for ISMIP6 data but designed to be generalisable to other datasets with the appropriate CF metadata.

By default outputs a gridded (time, y, x) mass balance zarr in kg/cell/yr, preserving the input coordinate system. Pass –prep-for-selrem to also flatten the result to the (time, point) schema expected by the SELREM entrypoint.

mass_balance_module.mass_balance_from_thickness_entrypoint.main(input_zarr: Path, output_path: Path, prep_for_selrem: bool = True, coarsen_factor: int = 1) → None

Convert ice thickness to mass balance and optionally prepare for SELREM.

Input dataset should have a CRS written with rioxarray and its variables should be annotated with standard_name/long_name attributes so that ice thickness and grounded fraction (if present) can be auto-detected. If the dataset lacks a ‘cell_area’ variable, cell area will be inferred from coordinate spacing if possible (regular 1-D x/y coordinates); otherwise an error is raised.

Parameters:

  • input_zarr (Path) – Input gridded zarr with x, y, and time coordinates, CF-attributed ice thickness (and optionally grounded fraction) variables, and CRS metadata written by rioxarray.

  • output_path (Path) – Where to write the output zarr.

  • prep_for_selrem (bool) – If True, additionally flatten the gridded output to the (time, point) schema expected by the SELREM entrypoint — including CRS reprojection to geographic coordinates and annual resampling if needed. Default True ( SELREM-ready output).

  • coarsen_factor (int) – Spatial coarsening factor applied when –prep-for-selrem is set. Mass is summed (mass-conserving); coordinates are averaged. Default 1.

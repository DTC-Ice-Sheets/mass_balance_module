mass_balance_module.mass_balance_enhance_elevation_data_entrypoint.main(input_geozarr: Path, elevation_change_data_path: Path, output_path: Path) → None

Command line entry point for the mass balance elevation data enhancement module.

Parameters:

  • input_geozarr (Path) – Path to the local GeoZarr dataset containing input features.

  • elevation_change_data_path (Path) – Path to the local zarr dataset containing the cumulative elevation-change data.

  • output_path (Path) – Where to save the output zarr dataset, which will contain the same data as input_geozarr but with the elevation-change, radar-distance and radar-mode features replaced by their per-year values.

DTC Ice Sheets: Mass Balance Module
===================================

The `mass_balance_module` is a sub-component of the
`Digital Twin Component for Ice Sheets (DTC-IS) <https://dtc-ice-sheets.org/>`_, an ESA-funded, EO-driven digital twin
project.

This software package fetches Earth Observation (EO) data and derives current and future mass balance predictions into the future.
It can be run independently or as part of the larger DTC-IS framework.

For a more interactive way of exploring the system, please visit the digital twin's
`dashboard <https://dashboards.dtc-ice-sheets.org/>`_.

The remainder of this documentation page provides an overview of the mass_balance_module and details about how
to get it running locally.
